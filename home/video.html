🔊 音声プレーヤー

映像はこの画面（Chromium）に表示されますが、音声は別経路で配信されます。 下の再生ボタンを1回押すと、動画の音声が流れるようになります。 （ブラウザの自動再生制限のため、最初の1回だけ手動操作が必要です）

💡 音が出ない場合: 一度動画サイトで再生ボタンを押してから、上の音声プレーヤーも再生してみてください。
💡 映像がカクつく場合: Codespaceのマシンスペックを上げると改善することがあります（Settings → Codespaces → Machine type）。
💡 文字を読む作業がメインの日は、ターミナルで Ctrl+C → npm run search がおすすめです。
