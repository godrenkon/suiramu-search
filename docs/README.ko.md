# 🌐 Suiramu Search（S.S.）

**"검색"과 "동영상 시청"에 집중한, 학생을 위한 학습 접근 환경**

Suiramu Search는 GitHub Codespaces에서 실제 Chromium 브라우저를 실행하고, 이를 통해 인터넷에 접속하는 도구입니다. 본인의 컴퓨터에는 아무것도 설치하지 않고, 브라우저만으로 사용할 수 있습니다.

![Status](https://img.shields.io/badge/status-active-brightgreen)

## 🎯 이것은 무엇인가요?

Suiramu Search(줄여서 **S.S.**)에는 **두 가지 모드**가 있습니다. 용도에 맞게 선택해서 실행하세요.

| 모드 | 이럴 때 | 특징 |
|---|---|---|
| 🔍 **검색 모드** | 자료 조사, 리포트 작성, 글 읽기 | 글자가 선명하고 가벼움 |
| 🎬 **동영상 모드** | YouTube 등의 동영상 시청 | 영상이 부드럽고 음성도 나옴 |

하나의 화면에서 모든 걸 처리하려 하지 않고, **용도에 따라 모드를 전환**함으로써 각각을 최대한 쾌적하게 만들었습니다.

---

## 🚀 사용 방법（3단계）

### 1단계: Codespace 열기

이 페이지의 초록색 **"Code"** 버튼 → **"Codespaces"** 탭 → **"Create codespace on main"** 클릭

잠시 기다리면 자동으로 설정이 시작됩니다（최초 1회만・3~5분 정도）。

### 2단계: 모드를 선택해서 실행

화면 하단의 **터미널**에 다음 중 하나를 입력하고 Enter를 누르세요.

**자료 조사・글을 읽고 싶을 때:**
```bash
npm run search
```

**동영상을 보고 싶을 때:**
```bash
npm run video
```

### 3단계: 화면 열기

- 화면 하단의 **"Ports" 탭** 클릭
- `6080` 행에 있는 지구본 아이콘（🌐）클릭
- 새 탭에서 Suiramu 화면이 자동으로 열립니다（접속 설정 화면 등은 나오지 않습니다）

**동영상 모드의 경우 한 가지 조작이 더 필요합니다:**
- 열린 화면 아래쪽에 있는 **🔊 오디오 플레이어**의 재생 버튼을 한 번 눌러주세요
- （브라우저가 오디오 자동 재생을 허용하지 않기 때문에, 최초 1회만 수동으로 눌러야 합니다）

---

## 🔁 실수로 Suiramu 탭을 닫아버렸다면

터미널로 돌아가 명령어를 다시 입력할 필요가 없습니다. 화면의 빈 곳（배경）을 우클릭하면 Suiramu를 다시 여는 메뉴가 나타납니다.

```
우클릭 → Suiramu → 🔍 Suiramu 열기（검색）
우클릭 → Suiramu → 🎬 Suiramu 열기（동영상）
```

클릭하면 바로 Suiramu 화면이 다시 열립니다. 백그라운드 서버（데이터 저장 등）는 계속 동작하고 있으므로 바로 원래 상태로 돌아갈 수 있습니다.

---

## 🔄 모드를 전환하고 싶을 때

터미널에서 `Ctrl + C`를 눌러 지금 모드를 정지한 후, 다른 명령어를 입력하세요.

```bash
# 검색 모드를 동영상 모드로 전환하는 예
Ctrl + C            ← 현재 모드 정지
npm run video        ← 동영상 모드 실행
```

## 🔍 검색 모드의 기능

- 화면 중앙의 검색창에서 검색하거나, URL을 직접 입력해 페이지를 열 수 있습니다
- 검색 엔진은 **Google / Bing / DuckDuckGo / Wikipedia** 중에서 선택할 수 있습니다（검색창 위 드롭다운）
- 자주 쓰는 사이트를 타일로 저장할 수 있습니다（＋ 버튼으로 추가, 우클릭으로 삭제）
- 여러 개의 탭・방문 기록은 실제 Chromium의 기능을 그대로 사용할 수 있습니다
  - `Ctrl + T`: 새 탭　`Ctrl + H`: 기록　`Ctrl + Shift + T`: 닫은 탭 복원

---

## 🎬 동영상 모드의 기능

- YouTube / Twitch / 니코니코 동화 / Vimeo로 가는 바로가기 타일이 처음부터 준비되어 있습니다
- 영상이 부드럽게 보이도록 화면 전송 설정을 동영상에 맞게 최적화했습니다
- 음성은 전용 전송 경로（Codespace 내 가상 스피커 → 오디오 스트림）로 재생됩니다
- 검색창에서도 동영상을 찾을 수 있습니다（YouTube 검색으로 이동）

### 음성에 대한 솔직한 설명

음성은 네트워크를 통해 전송되는 특성상 **완전히 끊김 없이・지연 없이**는 어렵습니다. 수백 밀리초~1초 정도의 지연이나, 네트워크 상황에 따라 끊김이 발생할 수 있습니다. 다만 실용적으로 문제없는 수준까지는 조정해 두었습니다.

영상이나 음성이 끊긴다면:
- Codespace의 머신 사양을 올리면 개선될 수 있습니다（`Settings → Codespaces → Machine type`）
- 동영상 사이트 자체의 화질 설정을 약간 낮추는 것도 효과적입니다

---

## 💾 데이터 저장에 대해（GitHub 계정 연동）

저장된 사이트（북마크）는 **당신 전용의 비공개 저장소** `<당신의 사용자명>/suiramu-data`에 자동으로 저장됩니다.

- 처음 실행할 때 이 저장소가 자동으로 생성됩니다（Private）
- 새 사이트를 추가하면 몇 초 후 자동으로 그곳에 저장됩니다
- 다른 Codespace를 새로 만들어도 동일한 데이터가 자동으로 불러와집니다
- 이메일 주소나 비밀번호는 전혀 입력・저장하지 않습니다（Codespace에 원래 있는 GitHub 인증을 그대로 사용합니다）

## 🌍 지원 언어

오른쪽 위의 드롭다운에서 화면 표시 언어를 전환할 수 있습니다:

🇯🇵 日本語 / 🇺🇸 English / 🇨🇳 中文 / 🇰🇷 한국어 / 🇪🇸 Español / 🇫🇷 Français

방문 중인 외부 사이트 자체를 번역하고 싶다면, Chromium 기본 번역 기능（페이지 우클릭 →「번역」）을 사용할 수 있습니다.

### 일본어・중국어・한국어 등의 입력에 대해

기본값으로는 영숫자만 입력할 수 있습니다. 일본어나 중국어 등 변환이 필요한 언어를 입력하고 싶다면, Codespace 터미널에서 **본인이 사용할 언어의 명령어를 한 번 실행**하세요. 입력 시스템의 기반（fcitx5）은 처음부터 설치되어 있으므로, 추가하는 것은 언어별 변환 엔진뿐입니다.

| 언어 | 터미널에서 실행할 명령어 |
|---|---|
| 🇯🇵 일본어 | `sudo apt-get install -y fcitx5-mozc` |
| 🇨🇳 중국어（간체） | `sudo apt-get install -y fcitx5-pinyin` |
| 🇹🇼 중국어（번체） | `sudo apt-get install -y fcitx5-chewing` |
| 🇰🇷 한국어 | `sudo apt-get install -y fcitx5-hangul` |
| 🇻🇳 베트남어 | `sudo apt-get install -y fcitx5-unikey` |
| 🇹🇭 태국어 | `sudo apt-get install -y fcitx5-libthai` |

설치 후, 다시 `npm run search`（또는 `video`）를 실행하면 사용할 수 있게 됩니다.

**사용법（공통）:**
- 입력창을 클릭하고 입력하면 자동으로 변환 후보가 나타납니다
- 반각/전각 키, 또는 `Ctrl + Space`로 입력 방식 ON/OFF를 전환할 수 있습니다

위 표에 없는 언어라도 `fcitx5-`로 시작하는 패키지가 준비되어 있는 경우가 많습니다. 터미널에서 다음과 같이 검색할 수 있습니다:

```bash
apt-cache search fcitx5
```

## 🔒 개인정보에 대해

- "계정" 아이콘은 표시 이름을 입력하는 것뿐인 간단한 프로필로, Codespace 내 브라우저에만 저장됩니다
- 저장 사이트 데이터는 당신 자신의 GitHub 계정 하위의 비공개 저장소에 저장되며, Suiramu 운영 측 서버로는 전송되지 않습니다
- 이메일 주소나 비밀번호는 요구하지 않습니다

## 🛠️ 기술 구성（궁금하신 분들을 위해）

| 기술 | 역할 |
|---|---|
| GitHub Codespaces | 실행 환경（당신 전용의 일회용 PC） |
| Xvfb | 가상 디스플레이 |
| Chromium | 실제로 동작하는 브라우저 본체 |
| x11vnc + noVNC | 화면을 웹 브라우저로 전송 |
| PulseAudio + ffmpeg | 동영상 모드 시 오디오 스트리밍 |
| GitHub CLI (`gh`) | 북마크의 영구 저장（당신 전용 비공개 저장소 사용） |

검색 모드와 동영상 모드는 noVNC・x11vnc의 압축 설정（화질과 프레임레이트의 균형）을 다르게 하여 각각의 용도에 맞게 최적화했습니다.

## ⚠️ 자주 묻는 질문

**Q. "Ports" 탭에서 6080번을 열었더니 Chromium이 아니라 아무것도 없는 데스크톱 화면（회색 배경 등）만 나옵니다**
A. 주된 원인은 두 가지입니다.

1. **`npm run search`나 `npm run video`를 실행하기 전에 포트를 열었다** — Suiramu 화면은 명령어를 실행해야 비로소 표시됩니다. 먼저 터미널에서 명령어를 실행한 후 포트 탭을 열어주세요.
2. **브라우저 실행에 실패했다** — 터미널에서 다음을 실행해 에러가 있는지 확인해보세요.
   ```bash
   cat /tmp/suiramu-chrome.log
   ```
   아무것도 표시되지 않거나 에러가 나온다면, 한 번 설정을 다시 실행해보세요.
   ```bash
   npm run setup
   ```

**Q. "GitHub 인증을 찾을 수 없습니다"라고 표시됩니다**
A. 북마크 자동 저장 기능（당신 전용 비공개 저장소에 저장）에 필요한 인증을 찾을 수 없을 때 나타나는 표시입니다. 동작 자체는 문제없이 계속되며, 이 경우 북마크는 Codespace 내에 일시적으로 저장됩니다. 영구 저장을 원하신다면 터미널에서 다음을 시도해보세요.
   ```bash
   gh auth login
   ```
   그 후 다시 `npm run search`（또는 `video`）를 실행하세요.

**Q. 동영상과 검색을 동시에 사용하고 싶습니다**
A. 현재는 하나의 Codespace에서 한 번에 하나의 모드만 실행하는 구조입니다. 동시에 사용하고 싶다면 브라우저에서 다른 Codespace를 하나 더 열어 그쪽에서 다른 모드를 실행해주세요（GitHub 무료 사용량 범위에 주의해주세요）。

**Q. Codespace의 이용 시간에 제한이 있나요?**
A. GitHub 계정 종류에 따라 무료 사용량이 정해져 있습니다. 자세한 내용은 GitHub 설정 페이지를 확인해주세요.

**Q. 로그인이 필요한 사이트（학교 포털 등）도 사용할 수 있나요?**
A. 사용할 수 있습니다. 실제 Chromium이 동작하고 있으므로, 평소처럼 로그인해서 조작할 수 있습니다.
