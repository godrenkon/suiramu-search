# 🌐 Suiramu Search（S.S.）

**「検索」と「動画視聴」に全振りした、学生のための学習アクセス環境**

GitHub Codespace 上で本物の Chromium を動かし、そこ経由でインターネットにアクセスするツールです。自分のパソコンには何もインストールせず、ブラウザだけで使えます。

## 🎯 これは何？

Suiramu Search（略して **S.S.**）には **2つのモード** があります。用途に合わせて選んで起動してください。

| モード | こんな時に | 特徴 |
|---|---|---|
| 🔍 **検索モード** | 調べもの、レポート作成、文章を読む | 文字がくっきり見える・動作が軽い |
| 🎬 **動画モード** | YouTube等の動画を見る | 映像がなめらか・音声も出る |

1つの画面で全部をこなそうとせず、**用途ごとにモードを切り替える**ことで、それぞれを徹底的に快適にしています。

---

## 🚀 使い方（3ステップ）

### ステップ1: Codespace を開く

このページの緑色の **「Code」** ボタン → **「Codespaces」** タブ → **「Create codespace on main」** をクリック

しばらく待つと、自動でセットアップが始まります（初回のみ・3〜5分程度）。

### ステップ2: モードを選んで起動する

画面下部の **ターミナル** に、次のどちらかを入力して Enter を押します。

**調べもの・文章を読みたい時：**
```bash
npm run search
```

**動画を見たい時：**
```bash
npm run video
```

### ステップ3: 画面を開く

- 画面下側にある **「ポート」タブ** をクリック
- `6080` の行にある地球アイコン（🌐）をクリック
- 新しいタブで Suiramu の画面が自動的に開きます（接続用の設定画面などは出ません）

**動画モードの場合はもう1つだけ操作が必要です：**
- 開いた画面の下の方にある **🔊 音声プレーヤー** の再生ボタンを1回押してください
- （ブラウザは音声の自動再生を許可しないルールになっているため、最初の1回だけ手動で押す必要があります）

---

## 🔁 間違ってSuiramuのタブを閉じてしまったら

ターミナルに戻ってコマンドを打ち直す必要はありません。画面の何もない場所（背景）を右クリックすると、Suiramuを再度開くためのメニューが出てきます。

```
右クリック → Suiramu → 🔍 Suiramuを開く（検索）
右クリック → Suiramu → 🎬 Suiramuを開く（動画）
```

これをクリックするだけで、もう一度Suiramuの画面が開きます。裏側のサーバー類（データ保存など）は動いたままなので、すぐに元の状態に戻れます。

---

## 🔄 モードを切り替えたい時

ターミナルで `Ctrl + C` を押して今のモードを止めてから、別のコマンドを入力してください。

```bash
# 検索モードを動画モードに切り替える例
Ctrl + C          ← 今のモードを停止
npm run video      ← 動画モードを起動
```

## 🔍 検索モードの機能

- 画面中央の検索バーで検索、または直接URLを入力してページを開けます
- 検索エンジンは **Google / Bing / DuckDuckGo / Wikipedia** から選べます（検索バー上のプルダウン）
- よく使うサイトをタイルとして保存できます（＋ボタンから追加、右クリックで削除）
- 複数タブ・閲覧履歴は本物の Chromium の機能をそのまま使えます
  - `Ctrl + T`：新しいタブ　`Ctrl + H`：履歴　`Ctrl + Shift + T`：閉じたタブを復元

---

## 🎬 動画モードの機能

- YouTube / Twitch / ニコニコ動画 / Vimeo への近道タイルが最初から並んでいます
- 映像がなめらかに見えるよう、画面の転送設定を動画向けに最適化しています
- 音声は専用の配信経路（Codespace内の仮想スピーカー → 音声ストリーム）で流れます
- 検索バーからも動画を探せます（YouTube検索に飛びます）

### 音声について、正直な説明

音声はネットワーク越しに配信している都合上、**完全に途切れなく・遅延ゼロ**というわけにはいきません。数百ミリ秒〜1秒程度のずれや、回線状況によっては途切れが起きることがあります。とはいえ実用上問題ないレベルには調整しています。

もし映像や音声がカクつく場合：
- Codespace のマシンスペックを上げると改善することがあります（`Settings → Codespaces → Machine type` からより高性能なマシンを選択）
- 動画サイト側の画質設定を少し下げてみるのも効果的です

---

## 💾 データの保存について（GitHubアカウント連携）

保存サイト（ブックマーク）は、**あなた専用の非公開リポジトリ** `<あなたのユーザー名>/suiramu-data` に自動保存されます。

- 初回起動時に、このリポジトリが自動で作成されます（Private）
- 新しいサイトを追加すると、数秒後に自動でそこへ保存されます
- 別のCodespaceを新しく作っても、同じデータが自動で読み込まれます
- メールアドレスやパスワードの入力・保存は一切行いません（Codespace に元々ある GitHub 認証をそのまま利用しています）

## 🌍 対応言語

右上のプルダウンから、画面の表示言語を切り替えられます：

🇯🇵 日本語 / 🇺🇸 English / 🇨🇳 中文 / 🇰🇷 한국어 / 🇪🇸 Español / 🇫🇷 Français

閲覧先の外部サイト自体を翻訳したい場合は、Chromium標準の翻訳機能（ページを右クリック→「翻訳」）が使えます。

### 日本語・中国語・韓国語などの入力について

デフォルトでは英数字のみ入力できます。日本語や中国語など、ローマ字変換が必要な言語を入力したい場合は、Codespaceのターミナルで**自分が使う言語のコマンドを1回実行**してください。入力システムの土台（fcitx5）は最初から入っているので、追加するのは言語ごとの変換エンジンだけです。

| 言語 | ターミナルで実行するコマンド |
|---|---|
| 🇯🇵 日本語 | `sudo apt-get install -y fcitx5-mozc` |
| 🇨🇳 中文（簡体字） | `sudo apt-get install -y fcitx5-pinyin` |
| 🇹🇼 中文（繁體字） | `sudo apt-get install -y fcitx5-chewing` |
| 🇰🇷 한국어 | `sudo apt-get install -y fcitx5-hangul` |
| 🇻🇳 Tiếng Việt | `sudo apt-get install -y fcitx5-unikey` |
| 🇹🇭 ภาษาไทย | `sudo apt-get install -y fcitx5-libthai` |

インストール後、もう一度 `npm run search`（または `video`）を実行し直すと使えるようになります。

**使い方（共通）：**
- 入力欄をクリックしてローマ字などで入力すると、自動で変換候補が出ます
- 半角/全角キー、または `Ctrl + Space` で入力方式のON/OFFを切り替えられます

上記の表にない言語でも、`fcitx5-` から始まるパッケージが用意されていることが多いです。ターミナルで次のように検索できます：

```bash
apt-cache search fcitx5
```

## 🔒 プライバシーについて

- 「アカウント」アイコンは表示名を入力するだけの簡易プロフィールで、Codespace内のブラウザにだけ保存されます
- 保存サイトのデータは、あなた自身のGitHubアカウント配下の非公開リポジトリに保存され、Suiramu運営側のサーバーには送信されません
- メールアドレスやパスワードの入力は求めません

## 🛠️ 技術構成（気になる人向け）

| 技術 | 役割 |
|---|---|
| GitHub Codespaces | 実行環境（あなた専用の使い捨てPC） |
| Xvfb | 仮想ディスプレイ |
| Chromium | 実際に動くブラウザ本体 |
| x11vnc + noVNC | 画面をWebブラウザに転送 |
| PulseAudio + ffmpeg | 動画モード時の音声ストリーミング |
| GitHub CLI (`gh`) | ブックマークの永続化（あなた専用の非公開リポジトリを使用） |

検索モードと動画モードでは、noVNC・x11vnc の圧縮設定（画質とフレームレートのバランス）を変えることで、それぞれの用途に最適化しています。

## ⚠️ よくある質問

**Q. 「ポート」タブの6080番を開いたら、Chromiumではなく何もないデスクトップ画面（灰色の背景など）しか出てこない**
A. 主な原因は2つです。

1. **`npm run search` や `npm run video` を実行する前にポートを開いてしまった** — Suiramuの画面は、コマンドを実行して初めて表示されます。先にターミナルでコマンドを実行してから、ポートタブを開いてください。
2. **ブラウザの起動に失敗している** — ターミナルで以下を実行して、エラーが出ていないか確認してください。
   ```bash
   cat /tmp/suiramu-chrome.log
   ```
   何も表示されない、またはエラーが出ている場合は、一度セットアップをやり直してみてください。
   ```bash
   npm run setup
   ```

**Q. 「GitHub認証が見つかりません」と表示される**
A. ブックマークの自動保存機能（あなた専用の非公開リポジトリへの保存）に必要な認証が見つからない場合の表示です。動作自体は問題なく続行され、この場合ブックマークはCodespace内に一時的に保存されます。永続化させたい場合は、ターミナルで次を試してください。
   ```bash
   gh auth login
   ```
   その後もう一度 `npm run search`（または `video`）を実行してください。

**Q. 動画も検索も同時に使いたい**
A. 現在は1つのCodespaceでは片方のモードのみ起動する設計です。同時に使いたい場合は、ブラウザで別のCodespaceをもう1つ開いて、そちらで別モードを起動してください（GitHubの無料枠の範囲にご注意ください）。

**Q. Codespaceの利用時間に上限はある？**
A. GitHubアカウントの種類によって無料枠が決まっています。詳しくはGitHubの設定ページをご確認ください。

**Q. ログインが必要なサイト（学校のポータル等）は使える？**
A. 使えます。本物のChromiumが動いているので、通常通りログインして操作できます。
