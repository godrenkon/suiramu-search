# 🌐 Suiramu

**Codespace上で動く、あなた専用のリモートブラウザ環境**

![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-active-brightgreen)

---

## 🎯 これは何？

自分の端末のネットワークに制限がかかっていても、**GitHub Codespace 上で本物の Chrome を動かして、そこ経由でインターネットにアクセスする**ためのツールです。

- サイトを勝手にコピー・保存することはしません
- あなた自身の Codespace が、あなた専用の「もう一台のパソコン」として動きます
- そこで起動した本物の Chrome に、あなたが直接触れて操作します

---

## 🚀 使い方

### 1️⃣ Codespace を開く

このリポジトリの緑色の **「Code」** ボタン → **「Codespaces」** タブ → **「Create codespace on main」**

### 2️⃣ セットアップを待つ

初回は自動で環境構築が始まります（3〜5分程度）。ターミナルに進捗が表示されます。

### 3️⃣ 起動する

セットアップ完了後、ターミナルで以下を入力：

```bash
npm start
```

### 4️⃣ ブラウザ画面を開く

- Codespace 下部の **「ポート」タブ** を開く
- `6080` 番ポートの地球アイコン（🌐）をクリック
- 新しいタブで本物の Chrome 画面が表示されます
- あとは普通のブラウザと同じように検索・クリック・入力ができます

---

## 🖥️ 画面の構成

起動すると **Suiramu** のホーム画面が表示されます：

- 上部中央：**Suiramu** ロゴ
- 左上：ハンバーガーメニュー（保存サイトについて・履歴の使い方・このツールについて・公式Twitter）
- 右上：アカウントアイコン（表示名の設定のみ・任意）
- 中央：検索バー（URLを直接入力してもOK）
- その下：保存済みサイト一覧（クリックで開く、＋で追加、右クリックで削除）
- 一番下：公式Twitter（[@Riku_verse_](https://x.com/Riku_verse_)）へのお知らせカード

### タブ・履歴（Chrome標準機能）

裏で動いているのは本物の Chromium なので、普段の Chrome と同じ操作ができます：

- `Ctrl + T` : 新しいタブ
- `Ctrl + H` : 閲覧履歴
- `Ctrl + Shift + T` : 閉じたタブを復元
- Codespace を再起動しても、直前に開いていたタブが自動的に復元されます

---

## 💾 データの保存について（GitHubアカウント連携）

保存サイト（ブックマーク）は、**あなた専用の非公開リポジトリ** `<あなたのユーザー名>/suiramu-data` に自動保存されます。

- 初回起動時に、このリポジトリが自動で作成されます（Private）
- 新しいサイトを追加すると、数秒後に自動でそのリポジトリへ保存されます
- **別のCodespaceを新しく作っても、同じデータが自動で読み込まれます**
- メールアドレスやパスワードの入力・保存は一切行いません（GitHub Codespace に元々ある認証をそのまま利用しています）

---

## 🔒 プライバシーについて

- 「アカウント」アイコンは**表示名を入力するだけ**の簡易プロフィールで、このCodespace内のブラウザにだけ保存されます
- 保存サイトのデータは、あなた自身のGitHubアカウント配下の非公開リポジトリに保存されます。Suiramu運営側のサーバーには一切送信されません
- メールアドレスやパスワードの入力は求めません

---

## ⚠️ できないこと・注意点

- これは「サイトを保存して公開する」ツールではありません。閲覧のたびに、あなた自身がその都度サイトへアクセスします
- Codespace は無料枠に月あたりの利用時間の上限があります（GitHubアカウントの設定を確認してください）
- 対象サイトの利用規約は通常通り適用されます。ログインが必要なサービスはそのままログインして使えます

## 🛠️ 技術構成

| 技術 | 役割 |
|------|------|
| GitHub Codespaces | 実行環境（あなた専用の使い捨てPC） |
| Xvfb | 仮想ディスプレイ |
| Chromium | 実際に動くブラウザ本体 |
| x11vnc | 画面をVNCで配信 |
| noVNC | VNCをWebブラウザで見れる形に変換 |
